# OfficePress logos and favicons

Owner: [Brand identity](../context/brand.md) and [Visual asset map](00077-officepress-visual-asset-map.md). Load when choosing the current editable SVG, PNG export, 16px favicon or a superseded original.

The current set has four suite SVG assets and 35 product SVG marks. Each root `kit/logos/` SVG byte-matches its KB master and has a PNG at the declared SVG size. The 36 current ICOs are single-size, PNG-backed 16 × 16 browser-tab assets. Use SVG/PNG for visible UI placements of at least 20px rather than enlarging the ICO. See [logo usage](00029-docs-logos-md.md) and the [Files/Forge revision](00403-officepress-files-forge-revision.md) for construction, family changes, planned-product limits, source IDs and conversion QA.
